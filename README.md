# Simple Calculator

A beginner-friendly Python calculator developed for the Codveda Technology Python Development Internship — Level 1, Task 1.

## Requirements
- Addition
- Subtraction
- Multiplication
- Division
- Separate functions for each operation
- Two user inputs
- Operation selection
- Division-by-zero handling

## Features
- Interactive command-line interface
- Numeric input validation
- Invalid-operation handling
- Multiple calculations in one session
- Unit tests using Python's built-in unittest framework

## Technologies
- Python 3
- VS Code
- Git
- GitHub

    codveda-python-level1-calculator/

    python3 calculator.py
